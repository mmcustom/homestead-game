## What this run is for

1. Measure what the new income lines really earn: Maple Syrup (Winter Y1, days 84 to 111), Ash, and Potash.
2. See whether a careful Pioneer can reach the day 112 payment ($573.39) and by how much, and how far short the second payment is.
3. Find out whether the game now teaches itself: do you find the steps (Tripod, Pot, hopper, Kettle, taps) without the checklist?

## Rules (same as before)

- New game, Pioneer tier, 5 acres. Play like a real player.
- NO F12, NO cash keys (PageUp), no Ctrl+Insert, Shift+Delete or Delete (those give free items).
- Time keys are fine for waiting (F7 speed, F5 skip a day). Write down when you used them. Speed changes distort income per real hour, but income per game day is still good.
- Avoid the Maple dev keys (Home, Shift+Home, Page Down). If you use one, note it.
- Save often. Keep a copy of the Saves folder before you start and tell Claude Code when you finish so it can restore it.
