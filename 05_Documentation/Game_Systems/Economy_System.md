# Homestead
## Economy System v1.0

Status: Design Draft

---

# Purpose

The Economy System supports homestead development.

Homestead is not a wealth-building simulator.

The economy exists to:

- Reward surplus production
- Enable property improvements
- Provide meaningful choices
- Support long-term self-sufficiency

The economy should never become the primary objective.

---

# Core Philosophy

Production should always follow:

Personal Use
↓
Stored Reserves
↓
Livestock Needs
↓
Surplus
↓
Market Sales

The homestead comes first.

# Surplus Management

The player must choose:

Store It

or

Sell It

Example:

100 lbs of potatoes

Option 1:

Store for Winter

Option 2:

Sell for Cash

Both choices have consequences.

---

# Winter Pressure

Economy decisions should become more meaningful as winter approaches.

Examples:

Selling too much food may create winter shortages.

Selling too much firewood may create heating problems.

Successful players balance cash flow and survival.

---

# Debt

Future System

Players may borrow money for:

- Wells
- Livestock
- Buildings

Debt should create risk.

---

# Design Rules

1. Survival is more important than profit.

2. Selling resources should always involve tradeoffs.

3. Players should never feel forced to sell everything.

4. Long-term planning should outperform short-term profit.

5. Wealth is not the victory condition.

Success is measured by self-sufficiency.
