# Homestead
## Plants: Berries v1.0

Status: Design Draft

---

# Purpose

Concrete, tunable stats for Blackberries and Raspberries, the two Berries species defined in Foraging_System.md. This document does not redefine the general Foraging mechanic — it's the per-species numbers that mechanic needs to actually run.

Grouped as one file, matching Foraging_System.md's own Resource Category structure.

---

# Design Role

Berries are Summer's peak-season resource per Foraging_System.md ("Peak gathering season"). Low effort to identify and harvest once a patch is discovered, moderate value, primarily fresh-eaten or lightly preserved rather than a Winter staple like Nuts.

---

# Blackberries

- **Season:** Summer (per Foraging_System.md)
- **Yield per harvest:** 3 units per patch — confirmed 2026-09-22 (Mike)
- **Regrowth:** Patch available again next Summer, matching Foraging_System.md's own existing example ("Berry Patch — Harvested: Summer, Available Again: Next Summer")
- **Uses:** Food, Preservation (dried), Trade — per Foraging_System.md
- **Nutritional role:** Light, quick food — meant for snacking/Hunger top-off, not a primary meal

---

# Raspberries

- **Season:** Summer, same window as Blackberries
- **Yield per harvest:** 3 units per patch
- **Regrowth:** Annual, same as Blackberries
- **Uses:** Food, Preservation, Trade
- **Nutritional role:** Same tier as Blackberries — confirmed 2026-09-22 (Mike): functionally interchangeable is fine, no differentiation needed

---

# Design Rules

1. Values on this page are confirmed baselines, not immutable — normal playtesting-driven tuning still applies.

2. Annual patch regrowth (available again the same season next year) follows Foraging_System.md's own existing example and should not be changed here without updating that doc too.

3. Berries are the lowest-effort, lowest-individual-value Foraging category — any future addition should preserve that relative to Fruit.md and Nuts.md's higher value/effort.

4. Blackberries and Raspberries are intentionally interchangeable — same yield, season, and uses. If either is ever differentiated later, update both entries together so they don't drift apart silently.
